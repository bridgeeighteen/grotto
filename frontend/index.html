    Middleware behavior

    Prompt injection
    A missing system message is filled. Low-information defaults such as “You are a helpful assistant” are replaced. Explicit system prompts are preserved.
    Image metadata
    EXIF, IPTC, XMP, comments, and timestamp chunks are stripped from inline base64 images without re-encoding pixels. URL-only outputs cannot be scrubbed by the gateway.
    Request logs
    Method, path, status, platform, and duration are logged. Message content, prompts, image bytes, and API keys are not.
    Upstream errors
    Platform errors become OpenAI-shaped envelopes. Credentials, internal hosts, and request IDs are removed before a response leaves the gateway.
